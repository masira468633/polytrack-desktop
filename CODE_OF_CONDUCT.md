# Code de conduite

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience
exempte de harcèlement pour tout le monde, quels que soient l'âge, le handicap,
l'identité ou l'expression de genre, le niveau d'expérience, la nationalité,
l'apparence, la race, la religion ou l'orientation sexuelle.

## Comportements attendus

- Faire preuve d'empathie et de respect.
- Accepter les critiques constructives.
- Se concentrer sur ce qui est le meilleur pour le projet et la communauté.
- Signaler les comportements inappropriés aux mainteneurs.

## Comportements inacceptables

- Propos insultants, discriminatoires, harcelants ou menaçants.
- Attaques personnelles ou politiques.
- Publication d'informations privées sans autorisation.
- Tout comportement déplacé dans un contexte professionnel.

## Portée

Ce code s'applique aux espaces du projet (issues, pull requests, discussions) et
lorsqu'une personne représente le projet en public.

## Application

Les mainteneurs peuvent supprimer, modifier ou rejeter tout contenu non conforme,
et sanctionner les comportements inappropriés (avertissement, exclusion
temporaire ou définitive).

Pour signaler un problème, ouvre une issue privée via la page Security ou
contacte les mainteneurs du dépôt.
